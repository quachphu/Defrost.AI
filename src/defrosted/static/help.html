Fair housing & safety

Matching and outreach use tenancy-relevant criteria only — budget, size, location, timing. The system doesn't use or infer protected characteristics, we watch for proxy effects, and decisions are logged so they can be audited. Full statement: Fair Housing.
It sends only what you approved, which limits this sharply. If our agent still gets something wrong, that's our responsibility — we stand behind what it says and will make it right with the other party.
